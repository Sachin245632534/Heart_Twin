# Heart Digital Twin ❤️

## Overview
This project implements a digital twin of the human heart that simulates blood flow and cardiovascular dynamics. 
It provides an interactive web interface to modify physiological parameters and observe their impact in real time.

## Objective
To build a virtual heart model that enables analysis of how changes in measurable physiological parameters affect cardiovascular behavior.

## Features
- Real-time heart simulation
- Adjustable parameters (heart rate, resistance, pressure)
- Interactive frontend (HTML, CSS, JavaScript)
- Dynamic visualization including graphs for flow and pressure

## Core Concepts
- Hemodynamics
- Lumped parameter modeling (Windkessel model)
- Flow and pressure simulation

## Tech Stack
### Frontend
- HTML
- CSS
- JavaScript

### Backend / Simulation
- Python / Java (depending on implementation)

## How It Works
The system simulates cardiovascular behavior using mathematical models. 
Users can modify parameters through the web interface, and the system updates dynamically to reflect changes in blood flow and pressure.

## Real-World Mapping
The model parameters are designed to correspond to real measurable physiological values, such as:
- Heart Rate (BPM)
- Blood Pressure (mmHg)
- Vascular Resistance
- Blood Flow Rate

This mapping enables more realistic simulation and potential real-world applicability.

## Use Case
Users can adjust parameters like arterial resistance or heart rate to observe their effect on cardiovascular performance.

## Future Scope
- Integration of machine learning for predictive analysis
- Personalized digital twin based on individual health data
- Enhanced physiological accuracy of the model
